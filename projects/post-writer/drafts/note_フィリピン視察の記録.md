# フィリピンの発展具合に驚いた。マニラ不動産視察の記録

（タイトル案：2. 梅田と十三が合わさったような街へ。マニラ不動産視察の記録 ／ 3. フィリピンの発展具合に驚いた。マニラを歩いた記録）

マニラの不動産を視察してきました。見たこと、感じたことを、写真と一緒に書きます。

■ 行く前と、行ったあと

正直に言うと、行く前のフィリピンのイメージと、見てきたものは、全然違いました。
発展具合が、本当にすごかったです。

■ 1. ビジネス街とファッションの街

最初に歩いたのは、ビジネス街とファッションの街です。
日本でいうと、梅田と十三が合わさったような場所でした。

ガラス張りの高層ビルが並んでいます。ヤシの木の遊歩道があり、噴水のある公園があります。
ショップやカフェが並ぶ通りを、買い物客が歩いていました。

本当に、びっくりしました。

（写真：ph-bgc-towers、ph-bgc-palm、ph-bgc-park）

■ 2. 1棟目の視察

1棟目は、高層階からの眺めが印象的でした。
遠くのビル群と、手前に広がる街並みが見えます。

共用部には、石畳の庭、ロビー、プールがありました。

（写真：ph-tour1-view-1、ph-tour1-view-2、ph-tour1-garden、ph-tour1-lobby、ph-tour1-pool-1、ph-tour1-pool-2）

■ 3. 2棟目：商業施設の上に、タワーマンション（The Seasons Residences）

2棟目は、The Seasons Residences です。
現地の商業施設「Mitsukoshi BGC」の上に、タワーマンションが建っています。私は、日本ではあまり見たことのない組み合わせでした。

マンションから、直通で三越まで降りられます。
私が歩いた範囲では、日本の食材を扱う売り場が印象に残りました。

今回見た中で、商業施設とつながったつくりが印象に残った一棟です。

（写真：ph-t2-sign、ph-t2-tower、ph-t2-backdrop、ph-t2-grocery）

■ 4. 2棟目の共用部

共用部は、和の雰囲気を取り入れたつくりでした。

・ロビーのラウンジ（ガラス越しに緑が見えます）
・プールと、小さな丸いプール
・キッズルーム（すべり台があります）
・畳の部屋と、木格子の仕切り

（写真：ph-t2-sofa、ph-t2-pool、ph-t2-pool-small、ph-t2-kids、ph-t2-tatami、ph-t2-screen）

■ 5. マニラを歩いて感じたこと

とにかく、人が多いです。外国人も多いです。
ただ、秩序はいまいちだと感じました。交通渋滞は、激しいです。

「人が多い」は、街の活気です。「秩序」と「渋滞」は、暮らしやすさの課題です。
良いところも、気になるところも、見てきました。

■ おわりに

見てきて、一番変わったのは、フィリピンへのイメージです。
日本ではあまり見かけないことが、フィリピンでは、当たり前のようにありました。それを、自分の目で見られたことが、今回の大きな収穫でした。
