# フィリピンの高層マンションの設備が、すごかった。（note 下書き2/3）

【利害関係のお知らせ】今回の視察は、ホテル代を現地の不動産会社に出してもらいました。航空券は自費です。私が代表のオンタイム合同会社は、海外の不動産会社と、代理店契約・コンサル契約を結んでいます。この記事は、特定の物件をすすめるものでも、投資をおすすめするものでもありません。この記事は、オンタイム合同会社の代表としての発信です。TERASSの業務とは関係ありません。

■ はじめに

マニラで、高層マンションを2棟、見てきました。
一番驚いたのは、共用部の設備です。

ホテルのようなつくりでした。

■ 1棟目：眺め、庭、プール

1棟目は、高層階からの眺めが印象的でした。遠くのビル群と、手前に広がる街並みが見えます。
共用部には、石畳の庭、ロビー、プールと東屋がありました。

（写真：ph-tour1-view-1、ph-tour1-view-2、ph-tour1-garden、ph-tour1-lobby、ph-tour1-pool-1、ph-tour1-pool-2）

■ 2棟目：和の雰囲気を取り入れたつくり（The Seasons Residences）

2棟目は、和の雰囲気を取り入れたつくりでした。

・ロビーのラウンジ：ガラス越しに、緑が見えます。木の天井と、落ち着いた家具があります。
・プールと、小さな丸いプール。
・キッズルーム：すべり台があります。
・畳の部屋：掘りごたつのような、くぼみのあるテーブルがあります。
・木格子の仕切り。
・ビリヤード台、会議室、ジム。

（写真：ph-t2-sofa、ph-t2-pool、ph-t2-pool-small、ph-t2-kids、ph-t2-tatami、ph-t2-screen）

■ 商業施設とつながる暮らし

2棟目は、現地の商業施設「Mitsukoshi BGC」の上に、建っています。
マンションから、直通で降りられます。
私が歩いた範囲では、日本の食材を扱う売り場が印象に残りました。

建物の地下には、コンビニと、ランドリー室もありました。

（写真：ph-t2-tower、ph-t2-backdrop、ph-t2-grocery）

■ 設備が多いことの、裏側

設備が多いことは、魅力です。
ただ、設備が多いほど、維持の費用がかかります。

その費用を、誰が、どう負担するのか。ここは、私は、まだ、確認できていません。

■ おわりに

見た目の豪華さだけで、良し悪しは決まりません。
設備と、立地と、維持のしくみを、合わせて見る必要があります。
