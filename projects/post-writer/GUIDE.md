# 投稿の自動下書きルール

毎日 Claude がこのルールで投稿を書き、`projects/x-poster/queue.txt` と
`projects/threads-poster/queue.txt` に足す。投稿は scheduled-post（毎日 07:07 / 12:07 / 20:37 / 22:37 JST、1日4本）が自動で行う。

## 補充のしかた
- 各キューの投稿（#で始まらない行）が **10本未満** になったら、10本になるまで足す（1日4本消費＝約2.5日分）
- 1行1投稿。改行は `\n` と書く。既存の行は書き換えない
- 足したら `python3 projects/post-writer/check_queue.py` で長さを確認してからコミットする
- 直近のキューと過去の投稿ネタと同じ話を繰り返さない

## 写真つきの投稿（X のみ）
- 行の最後に ` || ファイル名` を付けると、`projects/x-poster/images/` の写真つきで投稿される（カンマ区切りで最大4枚）
- 写真は、撮影場所などの情報を消してから入れる。人の顔が写る写真は、本人が使うと決めたものだけ
- Threads は今まで通り写真なし

## Threads（queue: projects/threads-poster/queue.txt）
- 今の Threads の書き方を続ける：です・ます、やわらかく短く、3〜4行
- 最後は「皆さんは〜ですか？」の問いで終わる
- トピックタグを1個だけ付ける（例: #不動産 #ドローン #AI活用 #大阪）。Threadsは1投稿1タグで、同じ話題に興味がある人のおすすめに乗りやすくなる
- 不動産・ドローン・AI・日常・家族をバランスよく

## Instagram（queue: projects/instagram-poster/queue.txt）
- 1日1本。毎朝 Claude が先頭の1行を Metricool で当日 21:00 JST に予約し、`posted.txt` に移す。キューが **3本未満** なら7本まで足す（10/21に、10/21〜11/01の12本をまとめて予約した。次は 11/02 以降の分から。予約の前に、Metricool の getScheduledPosts で、その日に別の投稿がないか見る）
- 写真は必須。`projects/instagram-poster/images/` の写真だけを使う（新しい写真が x-poster/images に入ったら `make_images.py` を実行してから使う）
- ad-poster の写真は「イメージ」で本人の撮影ではないので使わない。本人の写真として出せる写真だけ
- 本人のドローン動画は、リール（`|| 動画.mp4`、`videos/` に置く）にする。届く人が写真より多い。動画は ffmpeg で H.264・無音の音声トラック付き・メタデータ（位置情報）なしにしてから置く
- 同じ場所・同じイベントの写真は、カルーセル（2〜4枚）にまとめると見てもらいやすい
- 書き方は Threads と同じ：です・ます、やわらかく3〜4行、最後は「皆さんは〜ですか？」の問い
- 本文のあと1行空けて、ハッシュタグを3〜4個（場所・テーマ・ジャンル。例: #神戸 #神戸旅行 / #ちいかわ #名古屋グルメ / #不動産 #不動産投資）
- `posted.txt` を見て、直近2週間に使った写真・同じ話は使わない
