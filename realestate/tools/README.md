# 概要書の一括変換ツール

既存の「物件概要書」PDF を、現在の概要書の様式で作り直します。

- **元のファイルは変更しません。** 出力は `--out` で指定した別フォルダに、同じフォルダ構成で新規作成します
- 物件名・価格・面積・利回り・特記事項・発行者情報・作成日・書類番号は、元の書類の値をそのまま引き継ぎます（利回りは再計算しません）
- 写真と地図は、元の PDF に入っている画像をそのまま使います（地図サーバーへの接続は不要）
- 概要書の様式でない PDF（投資分析など）は自動でスキップします
- 元にない自動コメント（登記・法令の指摘）や、実効容積率の注記は付けません
- 結果は出力フォルダの `変換ログ.csv` に残ります（変換・スキップ・注意点）

## 準備（パソコンで一度だけ）

```
pip install pymupdf playwright
python -m playwright install chromium
```

## 使い方

まず読み取りだけ確認します（何も作りません）:

```
python realestate/tools/convert_sheets.py "C:\Users\<あなた>\Desktop\物件案内" --out "C:\Users\<あなた>\Desktop\物件案内_新形式" --dry-run
```

問題なければ `--dry-run` を外して実行します。複数のフォルダを続けて指定できます
（例: デスクトップの物件案内フォルダ、Google ドライブ for desktop の同期フォルダ `G:\マイドライブ\...`）。

## 注意

- 出力先には、入力と別のフォルダを指定してください（同じ場所だと中止します）
- 同じ書類が複数のフォルダにある場合も、それぞれ変換されます
- 読み取れない項目（「要確認」など）は、元の書類の表記のまま出ます。変換後は必ず目視で確認してください
- 元の様式が大きく違う PDF は、必須項目（物件名・価格・所在地）が読めないとスキップされ、ログに理由が残ります
- 写真・地図の位置は「左が写真、右が地図」の様式を前提にしています
