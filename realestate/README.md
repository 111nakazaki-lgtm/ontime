# 不動産ノート

物件DBを中心に、検索・進捗管理・比較・収支シミュレーションを一体化した、ブラウザだけで動く単一HTMLアプリです。

- 使い方: `realestate/index.html` をブラウザで開く（インストール不要）
- データ: ブラウザの localStorage に保存。CSV/JSON で書き出し・読み込み可能
- 初期データは架空のサンプル8件（「データ」タブでリセット・全消去できます）

## 機能
- ダッシュボード: 件数・平均価格・平均利回り・進捗/種別の内訳・利回りTOP5
- 物件検索: キーワード/種別/目的/進捗/価格上限/利回り下限/並び替え、★お気に入り
- 進捗管理: 検討中→内見済→申込→契約／見送りのボード
- 比較: 最大3件を並べ、有利な値を強調
- 収支シミュレーター: 表面・実質利回り、元利均等返済、CF、CCR、DSCR、損益分岐入居率、保有後の売却を含む手残り
- 概要書・登記分析: 物件概要書と登記分析書を自動生成（印刷/PDF保存・HTML保存）
  - 概要書: 物件の表示、土地・建物（登記）、法令・接道、取引条件、収益、登記の概要、留意事項、法定耐用年数と融資期間の目安
  - 登記分析書: 表題部・甲区・乙区の一覧、所有権の履歴と保有期間、総合判定（スコア）、指摘事項と対応、決済までのチェックリスト
  - 主なチェック: 売主と名義の一致、差押・仮登記等、差押後の贈与、短期保有、共有・相続、抵当権の残存と合計額、地目、未登記建物、旧耐震、面積の相違、建ぺい率・容積率、接道・セットバック、借地権、市街化調整区域

試算は所得税・減価償却・大規模修繕費を含まない概算です。

- 地図・写真: 概要書の冒頭にメイン写真・追加写真と周辺地図を掲載。写真は最大12枚（自動で縮小してブラウザ内に保存、物件カードにもサムネイル表示）。地図は国土地理院タイル（標準/淡色/航空写真）で、住所検索または緯度経度で位置指定。地図表示と住所検索にはネット接続が必要です。

登記分析は一般的な実務上の着眼点による簡易判定で、法的助言ではありません。原本の確認と専門家への相談を前提にしてください。
